# استاندارد کامنت‌نویسی فارسی

## کلاس‌ها
قبل از کلاس‌های مهم توضیح داده شود:
- این کلاس چه کاری انجام می‌دهد.
- متعلق به کدام لایه است.
- با چه بخش‌هایی ارتباط دارد.

## توابع
برای توابع عمومی:
- ورودی‌ها
- خروجی
- هدف عملیات

## منطق پیچیده
قبل از الگوریتم‌ها دلیل انتخاب روش پیاده‌سازی نوشته شود.

## ممنوع
- کامنت برای توضیح واضح‌ترین خطوط کد لازم نیست.
- کامنت نباید جای نام‌گذاری صحیح را بگیرد.
