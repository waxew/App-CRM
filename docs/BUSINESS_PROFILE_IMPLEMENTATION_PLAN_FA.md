# برنامه تکمیل ۱۰ پروفایل کسب‌وکاری W-CRM

## هدف
این پروژه باید یک هسته مشترک CRM داشته باشد و هر نسخه بر اساس Business Profile فعال ساخته شود.

5. auto_parts_store_001
6. jewelry_store_001
7. book_store_001
8. grocery_store_001
9. pet_store_001
10. omnichannel_store_001

## اصول پیاده‌سازی

- فقط یک پروفایل در هر Build فعال است.
- فعال‌سازی از Config انجام می‌شود.
- Core بین تمام پروفایل‌ها مشترک است.
- UI اختصاصی از طریق Theme، Widget، Asset و Field Schema ساخته می‌شود.
- اطلاعات ثابت داخل Config قرار می‌گیرد.

## مراحل تکمیل

1. تعریف Schema هر پروفایل
2. تعریف فیلدهای اختصاصی
3. تعریف ماژول‌های فعال
4. تعریف Dashboard Widgetها
5. تعریف Asset و Theme
6. اتصال به Runtime
7. مستندسازی فارسی
8. تست Build
