# پروفایل بوتیک و پوشاک

شناسه: `boutique_store_001`

## هدف
مدیریت فروش پوشاک با تمرکز بر تنوع سایز، رنگ، جنس و کالکشن.

## ماژول‌ها
Customer، Product، Inventory، Sales، Invoice، Accounting و Delivery.

## فیلدهای تخصصی
برند، سایز، رنگ، جنس، فصل و کالکشن.

## داشبورد
فروش امروز، موجودی سایزها، رنگ‌های پرفروش و کمبود موجودی.

## UI
Theme و Assetها با کلید `boutique` resolve می‌شوند و از Shared UI Engine استفاده می‌شود.
