# پروفایل فروشگاه موبایل

شناسه: `mobile_store_001`

## هدف
مدیریت فروش و موجودی دستگاه‌های موبایل با پشتیبانی از شناسه‌های یکتا و خدمات پس از فروش.

## ماژول‌ها
Customer، Product، Inventory، Sales، Invoice، Accounting، Delivery، Warranty، Repair و Serial Management.

## فیلدهای تخصصی
برند، مدل، حافظه، RAM، رنگ، IMEI، سریال و تاریخ گارانتی.

## داشبورد
فروش امروز، دستگاه‌های موجود، تعمیرات باز و گارانتی‌های فعال.

## UI
کلیدهای بصری `theme_mobile`، `hero_mobile` و `icon_mobile` از Schema خوانده می‌شوند؛ UI نباید شرط مستقیم برای موبایل داشته باشد.
