# پروفایل کتاب‌فروشی

شناسه: `book_store_001`

## هدف
مدیریت فروش و موجودی کتاب با اطلاعات نشر و شناسه ISBN.

## ماژول‌ها
Customer، Product، Inventory، Sales، Invoice، Accounting و Delivery.

## فیلدهای تخصصی
ISBN، نویسنده، ناشر، نوبت چاپ و دسته‌بندی.

## داشبورد
فروش امروز، موجودی کتاب، نویسنده پرفروش و کتاب‌های کم‌موجودی.

## UI
Theme/Asset از کلید `book` گرفته می‌شود و Terminology محصول روی «کتاب» تنظیم شده است.
