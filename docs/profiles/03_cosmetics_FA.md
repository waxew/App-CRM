# پروفایل آرایشی و بهداشتی

شناسه: `cosmetics_store_001`

## هدف
مدیریت کالاهای آرایشی و بهداشتی با توجه به تنوع رنگ، Batch و تاریخ انقضا.

## ماژول‌ها
Customer، Product، Inventory، Sales، Invoice، Accounting و Delivery.

## فیلدهای تخصصی
برند، دسته‌بندی، حجم، رنگ/شماره، بچ نامبر، تاریخ انقضا و کشور سازنده.

## داشبورد
فروش امروز، کالاهای نزدیک انقضا، برند پرفروش و موجودی.

## UI
Theme/Asset با کلید `cosmetics` از Profile Schema بارگذاری می‌شود.
