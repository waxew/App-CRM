# گزارش پیشرفت کامنت گذاری فارسی W-CRM

## هدف
اضافه کردن توضیحات فارسی استاندارد به بخش های مختلف پروژه بدون تغییر منطق برنامه.

## ترتیب بررسی
1. Core Model
2. Domain و UseCaseها
3. Database و Room
4. Repository
5. Dependency Injection
6. Featureها
7. UI و Compose

## قوانین
- کامنت باید دلیل وجود کلاس یا تابع را توضیح دهد.
- منطق تجاری توضیح داده شود.
- کامنت جایگزین نام گذاری صحیح نیست.
- هیچ کدی صرفاً برای اضافه کردن کامنت بازنویسی یا حذف نمی‌شود.
