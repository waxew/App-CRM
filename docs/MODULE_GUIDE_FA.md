# راهنمای ماژول‌های W-CRM

## Customer
مدیریت مشتریان، اطلاعات تماس و تاریخچه تعاملات.

## Product
مدیریت کالا و ویژگی‌های پایه محصول.

## Inventory
کنترل ورود، خروج و موجودی.

## Sales
ثبت عملیات فروش.

## Invoice
مدیریت فاکتور و وضعیت پرداخت.

## Warranty
مدیریت ضمانت کالاهای دارای شماره سریال.

## Repair
مدیریت درخواست‌های تعمیر.

## Business Profile
هر کسب‌وکار می‌تواند Attribute و Module اختصاصی خود را بدون تغییر Core اضافه کند.

## توسعه آینده
هر Module باید:
- مستقل باشد.
- وابستگی مستقیم به UI نداشته باشد.
- از قراردادهای Domain استفاده کند.
