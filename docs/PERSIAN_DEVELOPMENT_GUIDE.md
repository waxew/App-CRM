# راهنمای توسعه فارسی W-CRM

## هدف فایل
این سند مرجع فارسی معماری و توسعه پروژه W-CRM است.

## قوانین توسعه
- Core پروژه نباید برای Build ساده حذف یا کوچک شود.
- هر تغییر معماری باید مستند و Commit شود.
- منطق کسب‌وکار باید در Domain قرار گیرد.
- UI فقط مسئول نمایش و دریافت رویداد است.

## معماری
Presentation → Domain → Repository → Data → Database

## توضیح Moduleها

### core
هسته مستقل CRM شامل مدل‌ها، قراردادها و منطق اصلی.

### business_profile
تعریف قابلیت‌های اختصاصی هر نوع کسب‌وکار بدون تغییر Core.

### runtime
راه‌اندازی محیط برنامه و ثبت ماژول‌ها.

### feature
قابلیت‌های قابل مشاهده کاربر مانند مشتری، کالا، فروش و فاکتور.

## استاندارد کامنت‌گذاری
کدهای Kotlin باید برای بخش‌های مهم شامل توضیح فارسی باشند:
- هدف کلاس
- مسئولیت تابع
- دلیل وجود منطق پیچیده
- ارتباط با سایر لایه‌ها
